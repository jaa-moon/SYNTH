## What is Synth?

**Synth** is an enterprise-grade CLI tool that extracts text from documents and images and determines whether the content was written by a human or generated by AI. It runs entirely in your terminal — no web server, no browser, no GUI.

### Key Features

- 🔍 **Multi-Format Support** — Images (PNG, JPG, BMP…), PDF, DOCX, TXT, Markdown, and Apple Pages
- 📄 **Smart PDF Handling** — Direct text extraction for digital PDFs, automatic OCR fallback for scanned documents
- 🤖 **AI Detection** — Local HuggingFace models or any remote API (OpenAI, Anthropic, Google Gemini, Ollama, custom)
- ⚙️ **Easy API Setup** — Interactive wizard (`synth configure`) or inline flags (`--api-key`, `--api-url`)
- 🔌 **Strategy Pattern** — Swap detection backends without changing a line of code
- 🍎 **Hardware Agnostic** — Auto-detects CUDA (NVIDIA), MPS (Apple Silicon), or CPU
- 📁 **Batch Processing** — Scan entire directories with progress bars
- 🎨 **Rich TUI** — Colour-coded verdicts, AI-pattern highlighting, styled tables
- 📦 **PyPI-Ready** — Modern `pyproject.toml`, editable installs, typed codebase

### Supported File Types

| Format | Extensions | How it Works |
|---|---|---|
| **Images** | `.png`, `.jpg`, `.jpeg`, `.tiff`, `.tif`, `.bmp`, `.webp` | OpenCV preprocessing → EasyOCR extraction |
| **PDF** | `.pdf` | Direct text extraction; OCR fallback for scanned pages |
| **Word** | `.docx` | Paragraph and table text extraction |
| **Plain Text** | `.txt`, `.md`, `.markdown`, `.rst`, `.csv` | Direct file reading |
| **Apple Pages** | `.pages` | Embedded PDF extraction or XML parsing |

## Installation

### Prerequisites

- Python 3.10+
- pip or uv
- pipx (recommended for macOS/Linux users)

### Global Installation (Recommended)

The easiest way to install `synth` globally on your machine without breaking your system Python environments is using `pipx`:
```bash
pipx install "git+https://github.com/khushalv21/SYNTH.git"
```

### Development Installation

```bash
git clone https://github.com/khushalv21/SYNTH.git
cd SYNTH
pip install -e ".[dev]"
```

## Quick Start

### 1. Using Local Model (requires GPU or CPU)

```bash
# Verify an image
synth verify photo.png

# Verify a PDF document
synth verify report.pdf

# Verify a Word document
synth verify essay.docx

# Verify a plain text file
synth verify article.txt

# Scan an entire directory
synth verify ./documents/
```

### 2. Using Remote API (no GPU needed!)

#### Option A: Interactive Setup (recommended for first time)

```bash
synth configure
```

This walks you through choosing a provider (OpenAI, Anthropic, Google Gemini, Ollama, or custom), entering your API key, and saving the configuration.

Then simply:
```bash
synth verify report.pdf --engine api
```

#### Option B: Inline Flags (no setup needed)

```bash
# OpenAI
synth verify document.pdf --engine api --api-key sk-... --agent gpt-4o

# Anthropic
synth verify essay.docx --engine api --api-key sk-ant-... --api-url https://api.anthropic.com/v1/messages --agent claude-sonnet-4-20250514

# Google Gemini
synth verify article.txt --engine api --api-key AI... --api-url https://generativelanguage.googleapis.com/v1beta/openai/chat/completions --agent gemini-2.5-flash
```

## CLI Reference

### `synth verify`

```
synth verify <PATH> [OPTIONS]

Arguments:
  PATH  Path to a file or directory

Options:
  -e, --engine [local|api]  Detection strategy (default: local)
  -a, --agent TEXT          Model name or identifier
  -k, --api-key TEXT        API key (overrides .env)
  -u, --api-url TEXT        API endpoint URL (overrides .env)
  -l, --lang TEXT           OCR languages, comma-separated (default: en)
  --show-text / --no-text   Show extracted text panel (default: show)
```

### `synth configure`

Interactive wizard to set up API provider configuration.

### `synth info`

Show system information: Python version, hardware, available strategies, supported file types, API configuration status.

## Configuration

### Environment Variables

| Variable | Required | Description |
|---|:---:|---|
| `SYNTH_API_BASE_URL` | ✅ | Full API endpoint URL |
| `SYNTH_API_KEY` | ✅ | Authentication key |
| `SYNTH_API_MODEL` | ❌ | Model identifier |
| `SYNTH_PAYLOAD_MAP` | ❌ | Path to JSON payload mapping file |

### Priority Order

CLI flags → `.env` file → environment variables

See the [Universal API Guide](docs/UNIVERSAL_API_GUIDE.md) for advanced configuration options.
